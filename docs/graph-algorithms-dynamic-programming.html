Chapter 11 Graph Algorithms & Dynamic Programming

11.1 Shortest Path Algorithms

Shortest path algorithms form the backbone of routing protocols, spatial navigation, and network optimization. Given a weighted graph \(G = (V, E, w)\), the objective is to find a path between vertices that minimizes the sum of edge weights.

11.1.1 Single-Source Shortest Paths (SSSP)

11.1.1.1 Dijkstra’s Algorithm

Dijkstra’s algorithm solves SSSP for graphs with non-negative edge weights (\(w(e) \ge 0\)). It uses a greedy strategy, maintaining a set of settled vertices whose shortest distance from the source is known.

  • Edge Relaxation Step: For an edge \((u, v)\) with weight \(w(u, v)\):

\[\text{if } d[u] + w(u, v) < d[v] \implies d[v] = d[u] + w(u, v)\]

                     Edge Relaxation Principle
          Current d[v] = 10                  Relaxes to d[v] = 7
                 (v)                                (v)
                /                                  /
         w=3   /                            w=3   /
              /                                  /
            (u)  d[u] = 4                      (u)  d[u] = 4
  • Data Structure & Complexity:
  • Binary Heap: \(O((V + E) \log V)\)
  • Fibonacci Heap: \(O(E + V \log V)\)

11.1.1.2 Bellman-Ford Algorithm

When a graph contains negative edge weights, Dijkstra’s algorithm fails. The Bellman-Ford algorithm relaxes all \(E\) edges up to \(V - 1\) times.

  • Negative Cycle Detection: If an edge can still be relaxed during a \(V\)-th iteration, the graph contains a negative-weight cycle (meaning a shortest path is undefined as cost can approach \(-\infty\)).
  • Time Complexity: \(O(V \cdot E)\)

11.1.2 All-Pairs Shortest Paths (APSP)

11.1.2.1 The Floyd-Warshall Algorithm

Floyd-Warshall uses dynamic programming to compute the shortest paths between all pairs of vertices simultaneously.

  • State Definition: Let \(d_k(i, j)\) be the shortest path distance from \(i\) to \(j\) using only intermediate vertices from \(\{1, 2, \dots, k\}\).
  • Recurrence Relation:

\[d_k(i, j) = \min \Big( d_{k-1}(i, j), \; d_{k-1}(i, k) + d_{k-1}(k, j) \Big)\]

                  Floyd-Warshall Intermediate Node (k)
                              ( k )
                             ^     \
                            /       \  d_{k-1}(k, j)
             d_{k-1}(i, k) /         v
                         (i)--------->(j)
                           d_{k-1}(i, j)
  • Time Complexity: \(O(V^3)\)
  • Space Complexity: \(O(V^2)\)

11.2 Topological Sorting & DAG Dynamic Programming

Directed Acyclic Graphs (DAGs) represent networks with strict causal dependencies, such as course prerequisites, job scheduling, and compilation pipelines.

11.2.1 Topological Sort

A linear ordering of vertices in a DAG such that for every directed edge \((u, v)\), vertex \(u\) comes before vertex \(v\).

  • Kahn’s Algorithm (In-Degree Approach):
  1. Compute in-degrees for all vertices.
  2. Enqueue all vertices with \(\text{in-degree} = 0\).
  3. Dequeue \(u\), append to ordering, and decrement in-degrees of \(u\)’s neighbors. Repeat until queue is empty.
  • Complexity: \(O(V + E)\)
                    Topological Dependency Order
          (Math 1) -------> (Math 2) -------> (Graph Theory)
             \                                      ^
              +-------------------------------------+

11.2.2 Dynamic Programming on DAGs

Because DAGs contain no cycles, subproblems can be ordered topological-wise, enabling optimal evaluation in linear time \(O(V + E)\).

  1. Longest Path in a DAG:

\[\text{dist}[v] = \max_{(u, v) \in E} \big( \text{dist}[u] + w(u, v) \big)\]

  1. Counting Paths in a DAG:

\[\text{paths}[v] = \sum_{(u, v) \in E} \text{paths}[u]\]

11.3 11.3 Dynamic Programming: Graph Decomposition

Complex graph problems that are NP-hard on arbitrary graphs can often be solved in linear or polynomial time on trees and low-treewidth graphs using dynamic programming.

11.3.1 Tree Dynamic Programming

To solve problems on trees, we process subtrees bottom-up from leaves to the root.

11.3.1.1 Example: Maximum Independent Set on a Tree

Let \(T\) be a rooted tree. For every vertex \(u\), define two states:

  • \(DP[u][0]\): Size of maximum independent set in \(u\)’s subtree when \(u\) is not included.
  • \(DP[u][1]\): Size of maximum independent set in \(u\)’s subtree when \(u\) is included.
                   Tree DP Recurrence Hierarchy
                              (u)  <-- Root
                             /   \
                           (v1)  (v2) <-- Children

11.3.1.2 Recurrence Equations

\[\begin{aligned} DP[u][0] &= \sum_{v \in \text{children}(u)} \max \Big( DP[v][0], \; DP[v][1] \Big) \\ DP[u][1] &= 1 + \sum_{v \in \text{children}(u)} DP[v][0] \end{aligned}\]

  • Time Complexity: \(O(V)\), since every node is processed once in post-order traversal.
