Chapter 13 Practice Problem Set: Chapters 1–12

13.0.1 Chapter 1: Fundamentals & Basic Definitions

  1. Degree Sequence Analysis: Determine whether the sequence \((5, 4, 3, 3, 2, 1)\) can represent the degree sequence of a simple graph. If not, explain which condition is violated.
  2. Subgraphs: Given the complete graph \(K_4\), calculate the total number of induced subgraphs and edge-induced subgraphs.
  3. Graph Isomorphism: Draw two non-isomorphic 3-regular graphs with 6 vertices. Show why they are not isomorphic using graph invariants.

13.0.2 Chapter 2: Trees & Spanning Trees

  1. Prufer Sequences: Find the Prufer sequence for a tree with vertex set \(\{1, 2, 3, 4, 5, 6\}\) and edge set \(E = \{(1, 2), (1, 3), (1, 4), (4, 5), (4, 6)\}\).
  2. Minimum Spanning Trees: Trace both Kruskal’s and Prim’s algorithms on a graph with vertices \(\{A, B, C, D, E\}\) and edge weights:
  • \((A, B) = 1\), \((A, C) = 4\), \((B, C) = 2\), \((B, D) = 5\), \((C, D) = 1\), \((D, E) = 3\).
  1. Tree Properties: Prove that any connected graph \(G = (V, E)\) with \(\vert{}E\vert{} = \vert{}V\vert{} - 1\) is a tree.

13.0.3 Chapter 3: Eulerian & Hamiltonian Graphs

  1. Eulerian Paths: Determine if a graph with degree sequence \((4, 4, 3, 3, 2)\) contains an Eulerian path or an Eulerian circuit.
  2. Dirac’s Theorem: Apply Dirac’s Theorem (\(\deg(v) \ge n/2\)) to show whether a 4-regular graph on 7 vertices is guaranteed to be Hamiltonian.
  3. Knight’s Tour: Formulate the Knight’s Tour problem on an \(8 \times 8\) chessboard as a Hamiltonian path problem on a graph. Specify the vertex set \(V\) and edge condition \(E\).

13.0.4 Chapter 4: Planarity & Graph Embeddings

  1. Planar Representation: Redraw the complete bipartite graph \(K_{2,4}\) to explicitly show that it is planar (with no crossing edges).
  2. Dual Graphs: Construct the geometric dual graph \(G^*\) for a 5-vertex planar graph formed by a cycle \(C_4\) with one diagonal added.
  3. Subdivisions & Minors: Show that the Peterson graph contains a subdivision of \(K_{3,3}\), proving its non-planarity via Kuratowski’s Theorem.

13.0.5 Chapter 5: Graph Colorings

  1. Greedy Coloring Bound: Find an ordering of vertices for a cycle \(C_6\) such that the greedy coloring algorithm uses 3 colors instead of its optimal 2 colors.
  2. Chromatic Polynomial: Compute the chromatic polynomial \(P(G, k)\) for a path graph \(P_4\) and a cycle graph \(C_4\).
  3. Five Color Theorem: Outline the key steps in the proof of the Five Color Theorem for planar graphs, highlighting where Kempe chains are used.

13.0.6 Chapter 6: Directed Graphs & Connectivity

  1. Strongly Connected Components: Run Kosaraju’s or Tarjan’s algorithm to identify the strongly connected components (SCCs) of a directed graph with edges:
  • \(A \to B\), \(B \to C\), \(C \to A\), \(C \to D\), \(D \to E\), \(E \to D\).
  1. Menger’s Theorem: State the edge version of Menger’s Theorem. Identify the minimum edge-cut and maximum edge-disjoint paths between two vertices \(u\) and \(v\) in \(K_5 \setminus \{e\}\).
  2. Tournament Graphs: Prove that every tournament graph contains a Hamiltonian path.

13.0.7 Chapter 7: Network Flows & Matching

  1. Residual Network Computation: Given a network with flow \(f(s, u) = 3 / c(s, u) = 5\) and \(f(u, t) = 3 / c(u, t) = 3\), draw the residual graph \(G_f\) and list all forward and backward residual edge capacities.
  2. Augmenting Paths: Trace one execution step of the Edmonds-Karp algorithm on a simple flow network using BFS to select the shortest augmenting path.
  3. Hall’s Condition: Verify whether Hall’s Condition holds for a bipartite graph \(A = \{a_1, a_2, a_3, a_4\}\), \(B = \{b_1, b_2, b_3, b_4\}\) with edges \((a_1, b_1), (a_1, b_2), (a_2, b_1), (a_3, b_3), (a_4, b_3), (a_4, b_4)\).

13.0.8 Chapter 8: Spectral & Algebraic Graph Theory

  1. Spectrum Bounds: Given a 3-regular graph \(G\) with 8 vertices, state its largest adjacency eigenvalue \(\lambda_1\).
  2. Laplacian Matrix Formulation: Construct the Laplacian matrix \(L\) for a star graph \(K_{1,4}\). Verify that the sum of each row equals 0.
  3. Graph Partitioning: Explain how the sign of the entries in the Fiedler vector (eigenvector corresponding to \(\mu_2\)) can be used to partition a graph into two clusters.

13.0.9 Chapter 9: NP-Completeness & Approximation Algorithms

  1. Reductions: Prove that Independent Set \(\le_p\) Vertex Cover by constructing a polynomial-time reduction between the two problems.
  2. 2-Approximation Execution: Run the edge-matching 2-approximation algorithm for Vertex Cover on a star graph \(K_{1,5}\). Compare the algorithm’s cover size with the optimal cover size.
  3. Metric TSP Bound: Explain why the triangle inequality \(w(u, v) \le w(u, w) + w(w, v)\) is essential for proving the 2-approximation bound in MST-based TSP.

13.0.10 Chapter 10: Random Graphs & Complex Networks

  1. Erdős–Rényi Edge Probability: Compute the exact probability that \(G(4, 0.5)\) produces a complete graph \(K_4\).
  2. Threshold Functions: For \(G(n, p)\), determine whether a graph with edge probability \(p(n) = \frac{1}{n^2}\) is connected asymptotically almost surely.
  3. Preferential Attachment: In a Barabási–Albert model with initial nodes \(\{v_1, v_2\}\) having degrees \(d(v_1) = 3\) and \(d(v_2) = 1\), calculate the probability that a new node attaches to \(v_1\).

13.0.11 Chapter 11: Graph Algorithms & Dynamic Programming

  1. Dijkstra vs. Bellman-Ford: Construct a 3-vertex directed weighted graph with a negative edge weight where Dijkstra’s algorithm fails to find the shortest path.
  2. DAG Shortest Path: Find the shortest path from \(s\) to \(t\) in a DAG with edges \((s, a, 2), (s, b, 4), (a, b, 1), (a, t, 7), (b, t, 2)\) using topological ordering.
  3. Tree DP Recurrence: Compute \(DP[root][0]\) and \(DP[root][1]\) for a tree rooted at \(R\) with children \(C_1, C_2\), where \(C_1\) is a leaf and \(C_2\) has one leaf child \(C_3\).

13.0.12 Chapter 12: Advanced Topics & Open Problems

  1. Minor Elimination: Show that \(K_3\) is a minor of \(K_4 \setminus \{e\}\) by listing the sequence of edge/vertex deletions or contractions.
  2. GNN Message Passing: Compute one layer of neighborhood aggregation for a node \(v\) with neighbors \(N(v) = \{u_1, u_2\}\) with feature vectors \(\mathbf{h}_{u1} = [1, 2]^T\) and \(\mathbf{h}_{u2} = [3, 0]^T\) using mean aggregation.
  3. Hadwiger’s Conjecture: Verify Hadwiger’s Conjecture (\(\chi(G) \le k - 1\) for \(K_k\)-minor-free graphs) for a cycle graph \(C_5\).
